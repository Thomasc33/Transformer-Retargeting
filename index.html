📖 Project README

ℹ️ About TMR

Transformer Motion Retargeting (TMR) is a privacy-preserving skeleton-based action recognition system that uses transformer architecture to retarget motion from one person to another while preserving action semantics and protecting identity information.

Key Features:

  • 🎯 Action Recognition (AR) - Preserves action semantics
  • 🔒 Re-Identification (RI) - Protects identity information
  • 🚀 Transformer Architecture - State-of-the-art performance
  • 📊 Multiple Datasets - NTU RGB+D 60/120, ETRI

Current Status: The model requires retraining with cooperative AR loss to improve action preservation. See RETRAINING_PLAN.md for details.

🎯 Metrics Explained

AR Accuracy Action Recognition

Measures how well the retargeted skeleton preserves the original action. Higher is better (target: >40%).

RI Target Re-Identification

Measures if the retargeted skeleton is recognized as the target person. Higher is better (target: >50%).

Privacy Score Identity Protection

Measures how well the original identity is protected. Higher is better (target: >80%).

🚀 Quick Start

Run Interactive CLI:

python tmr.py

Evaluate TMR:

python eval_anonymization_v2.py --only-tmr --dataset ntu --setting cv --test-samples 100

Check Status:

python quick_test_tmr.py
